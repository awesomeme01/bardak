# Происхождение звуков

**Источник:** подборка «Звуки игральных карт» — <https://zvukipro.com/predmet/1562-zvuki-igralnyh-kart.html>.
Условия сайта разрешают использование «в частных, личных, творческих и образовательных
проектах»; сами материалы, по словам сайта, собраны пользователями из свободного интернета.
Игра — личный некоммерческий проект, что под эти условия попадает. Для коммерческого
использования звуки пришлось бы заменить.

## Что было изменено при импорте

1. Из тридцати звуков подборки отобраны десять коротких (фоновые записи тасовок
   на 30–110 секунд в игре не нужны).
2. У каждого обрезана тишина по краям (порог 2 % от пика, 10 мс запаса спереди),
   пик выровнен к −1 дБFS, края сглажены фейдом 5 мс.
3. Перекодированы в моно AAC 96 кбит/с (`.m4a`) — играет во всех браузерах.
4. Файлы названы по событиям игры, имя — контракт со звуковым модулем фронта
   (`front-bardak/src/lib/sound.svelte.js`):

| Файл | Событие игры | Оригинал на сайте |
|---|---|---|
| `card-play.m4a` | `CARD_ATTACKED` — ход картой | «Положил козырь на стол» |
| `card-defend.m4a` | `CARD_DEFENDED` — отбился | «Вскрываем карты на стол» |
| `card-transfer.m4a` | `ATTACK_TRANSFERRED` — перевод | «Подвинули карту следующему игроку» |
| `card-draw.m4a` | `CARDS_DRAWN` — добор из колоды | «Взяли одну карту из колоды» |
| `cards-taken.m4a` | `CARDS_TAKEN` — забрал со стола | «Взяли часть своих карт в руки» |
| `round-beaten.m4a` | `ROUND_BEATEN` — бито | «Выбросил все карты на стол» |
| `card-hang.m4a` | `CARD_HUNG` — навес | «Карты вылетают из коробки» |
| `deal.m4a` | новая раздача (смена `dealNo`) | «Разбрасываем колоду перед собой» |
| `trump-reveal.m4a` | `HIDDEN_TRUMP_REVEALED` — потайной козырь | «Звук игральных карт» |
| `match-over.m4a` | `MATCH_OVER` — итог матча | «Бросаем карты одну за другой» (первые 2.6 с) |
