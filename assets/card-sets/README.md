# Наборы дизайна карт

Каждый набор — папка с картинками. Один набор = один комплект карт, выбирается при создании
стола. Подробности модели — `planning/06-card-design-system.md`.

```
card-sets/
├── classic/          ← набор по умолчанию, PNG 500×726
│   ├── 2-diamonds.png … A-diamonds.png     (полная колода 52 карты,
│   ├── 2-hearts.png   … A-hearts.png        в игре используются 6…A)
│   ├── 2-spades.png   … A-spades.png
│   ├── 2-clubs.png    … A-clubs.png
│   ├── Joker.png
│   └── back.png
├── classic-svg/      ← тот же дизайн вектором, SVG
└── <новый-набор>/    ← та же структура
```

Происхождение и внесённые изменения — в [CREDITS.md](CREDITS.md).

## Имена файлов — это контракт

| Что | Имя | Примеры |
|---|---|---|
| Карта | `<ранг>-<масть>.png` | `6-diamonds.png`, `10-hearts.png`, `A-spades.png` |
| Джокер | `Joker.png` | один файл на всех джокеров |
| Рубашка | `back.png` | |

- Ранги: `6 7 8 9 10 J Q K A` (в наборах лежат также `2 3 4 5` — про запас)
- Масти: `diamonds`, `hearts`, `spades`, `clubs`
- Обязательный минимум: **36 + Joker + back = 38 файлов**

Имя файла совпадает с кодом карты в БД и в протоколе — никакого преобразования между ними
нет. Поэтому переименовывать файлы нельзя: на эти коды завязан весь исторический лог партий.

Джокеров в колоде столько, сколько игроков (`Joker-1` … `Joker-5`), но рисуются они одним
файлом `Joker.png`.

## Как добавить набор

1. Создать папку с кодом набора.
2. Положить все 38 файлов с точными именами.
3. Зарегистрировать набор (SQL-миграция на MVP, позже — админский эндпоинт).

Сервер проверяет полноту покрытия при регистрации: набор с пропущенной картой нельзя выбрать
при создании стола.

**Проверить глазами:** подними бэкенд и фронт и открой
`http://localhost:5173/preview-cards.html` — страница показывает все карты набора и обводит
красным те, что не загрузились. Быстрый способ поймать опечатку в имени файла.

## Требования к картинкам

- Соотношение сторон **1 : 1.452** у всех карт набора (как в `classic`: 500×726).
- Прозрачный фон за скруглёнными углами (RGBA), радиус скругления ≈ 3.4% ширины.
- PNG или SVG. Для SVG — расширение `.svg` и `format: "svg"` в манифесте.
- Все карты набора одного размера: клиент раскладывает их по сетке и не подгоняет
  пропорции поштучно.
