# Матрица миграции тестов

Каждый тест, проходящий на baseline Java (`docs/java-baseline.md`, коммит `575d81f`),
обязан получить проходящий эквивалент в Go — либо обоснованный отказ.

**Правило отказа строгое.** `skipped` допустим ТОЛЬКО для чистой Java/Spring-специфики:
наличие аннотации, подъём пустого контекста, проверка связывания бинов без бизнес-смысла.
Если тест хоть где-то трогает JSON, код ответа, SQL, правило игры, транзакцию,
авторизацию или конкурентность — эта часть переносится. Смена языка обоснованием
не является.

Переносится **смысл**, а не реализация: шесть `@ParameterizedTest` становятся табличными
тестами Go, `@Tag("integration")` — тестом с Testcontainers for Go.
