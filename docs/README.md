сравнивать станет не с чем.

сломано в эталоне; повторять эти дефекты в Go не нужно, а вот знать о них — обязательно,
иначе исправление выглядит как расхождение.

## Почему Java ещё здесь

`back-bardak` — легаси, но не мусор: differential-прогон сравнивает **живую Java с Go**
(`tests/contract/compare.mjs`), а по сокету он не гонялся ни разу. Пока это не сделано,
эталон нужен работающим — и это ЕДИНСТВЕННАЯ оставшаяся причина.

Две других уже сняты: ассеты карт переехали в `assets/` в корне репозитория, а схемой
базы теперь владеет Go (MD-006) — он накатывает её сам, включая пустую базу.
