# VPN для Telegram — как подключиться

Через этот VPN идёт **только Telegram**: приложение на телефоне и компьютере, а также
веб-версия в браузере. Весь остальной интернет (сайты, YouTube, банки, рабочая сеть) идёт
как обычно, мимо VPN. Настраивать что-то внутри Telegram не нужно.

## 1. Получи свой конфиг

Попроси у Шабдана конфиг **для каждого своего устройства отдельно**:

- для телефона — **QR-код**;
- для компьютера — **файл `имя.conf`**.

⚠️ Конфиг — это твой личный ключ. Не пересылай его другим и не открывай один конфиг на двух
устройствах сразу: они будут выбивать друг друга. Нужно ещё устройство — попроси ещё конфиг.

## 2. Поставь WireGuard и добавь конфиг

### iPhone / iPad
1. Установи **WireGuard** из App Store.
2. Нажми **«+»** → **«Создать из QR-кода»** → наведи камеру на QR.
3. Введи любое имя, например `telegram`, → **«Разрешить»** добавить конфигурацию VPN.
4. Включи тумблер.

### Android
1. Установи **WireGuard** из Google Play.
2. Нажми **«+»** → **«Сканировать QR-код»**.
3. Введи имя, включи тумблер, разреши подключение VPN.

### macOS
**Вариант A — приложение (удобнее):**
1. Установи **WireGuard** из App Store.
2. Значок WireGuard в строке меню → **«Импорт туннеля из файла…»** → выбери свой `.conf`.
3. **«Разрешить»** добавить конфигурацию VPN → **«Активировать»**.

**Вариант B — через Homebrew (без App Store):**
```sh
brew install wireguard-tools
sudo wg-quick up ~/Downloads/имя.conf     # включить
sudo wg-quick down ~/Downloads/имя.conf   # выключить
```
После перезагрузки туннель сам не поднимется — включать заново.

### Windows
1. Скачай WireGuard с <https://www.wireguard.com/install/>.
2. **«Импорт туннеля из файла»** → выбери свой `.conf` → **«Подключить»**.

### Linux
```sh
sudo apt install wireguard-tools    # или аналог в твоём дистрибутиве
sudo wg-quick up ./имя.conf
```

## 3. Проверь

1. Включи VPN.
2. Открой Telegram или <https://web.telegram.org> — сообщения должны грузиться.
3. В WireGuard у туннеля должно быть **«Последнее рукопожатие: N секунд назад»**
   и расти счётчик **«Получено»**.

VPN можно держать включённым постоянно: на остальной интернет и заряд батареи он почти не
влияет — через него идёт только Telegram.

## Если не работает

| Что видно | Что делать |
|---|---|
| Рукопожатия нет совсем | Сеть не пропускает UDP (бывает в офисном и гостевом Wi-Fi). Проверь через мобильный интернет |
| На работе не подключается или отваливается рабочий VPN | Два VPN могут конфликтовать — выключи этот на время рабочих задач |
| Раньше работало, а теперь нет | Возможно, Telegram сменил адреса и конфиги обновили — попроси новый |
| Ничего не помогает | Попроси у Шабдана ссылку на прокси — она настраивается прямо в приложении Telegram (но в веб-версии не работает) |

Если пишешь Шабдану о проблеме — назови имя своего конфига и что показывает WireGuard
(есть ли рукопожатие).
